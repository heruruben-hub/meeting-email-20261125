A one-line joke about a meeting that should have been an email, written for the make.fun bounty "The Meeting That Should Have Been an Email".

The program does exactly one thing: it writes that single funny line to `/output/entry.txt`.

The joke plays on a familiar office absurdity: a long meeting spent talking about an email nobody has actually read yet.

Running it takes one command, and the output is a single line of plain text under 200 characters.

## Run it

```sh
node main.ts
```
